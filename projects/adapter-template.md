# 项目适配器模板

在目标业务仓库填写。每项路径都应在约定的基线提交上可定位。

| 项目资料 | 填写内容 |
|---|---|
| 标识与范围 | 项目 ID、仓库地址、默认分支、职责、协作方 |
| 工程入口 | 项目说明、工程规范、依赖清单及对应路径 |
| 模块关系 | 模块路径、入口、上游/下游、数据与接口所有者 |
| 技术约束 | 运行时版本、契约、异常、身份与数据隔离、迁移要求 |
| 执行约定 | 分支方式、允许的操作、实际可用的构建/测试命令 |
| 资料入口 | 架构、API、DDL、任务与归档目录；记录最后核对的提交 |
| 差异与未知项 | 已核验事实、设计目标、尚缺证据与责任人 |
